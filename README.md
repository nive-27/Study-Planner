# 📚 Study Planner

A personal study-planning application built with Python and Streamlit to help students organise tasks, track study time, and monitor their progress.

## ✨ Features

- **Task Management:** Add, edit, complete, delete, and search tasks.
- **Priority Management:** Organise tasks by high, medium, and low priority.
- **Deadline Tracking:** View pending and overdue tasks.
- **Study Time Tracker:** Record study sessions by subject.
- **Focus Timer:** Use a timer to stay focused during study sessions.
- **Weekly Analytics:** Visualise study time and track study consistency.
- **Data Persistence:** Store tasks and study history in JSON files.
- **Custom UI:** A personalised dark-purple and lavender theme.

## 🛠️ Technologies Used

- Python
- Streamlit
- JSON
- Pathlib
- Datetime

## 🚀 How to Run

1. Install Python on your computer.
2. Install Streamlit:

   ```bash
   py -m pip install streamlit
   ```

3. Navigate to the project folder in your terminal.
4. Run the application:

   ```bash
   py -m streamlit run app.py
   ```

5. Open the local URL displayed in your terminal.

## 📁 Project Structure

- `app.py` — Main application.
- `tasks.json` — Saved task data.
- `study_log.json` — Saved study sessions.
- `README.md` — Project documentation.

This project was created to make study planning, focus tracking, and progress monitoring easier through a simple, interactive application.
